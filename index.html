Questions fréquentes & Transparence

Faut-il installer un logiciel ou un compte Canva ?

Non ! Le studio est un fichier HTML autonome qui s'ouvre d'un double-clic dans Chrome, Edge, Safari ou Firefox, même sans connexion Internet.

Le QR code fonctionne-t-il vraiment hors-ligne ?

Oui. L'encodeur ISO/IEC 18004 est intégré directement dans le fichier local : tout téléphone scanne le QR code imprimé vers votre lien ou message secret.
